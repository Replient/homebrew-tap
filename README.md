# Knwlge Homebrew tap

```bash
brew tap replient/tap
brew install replient/tap/knwlge-enterprise   # the Enterprise Server: then `knwlge-enterprise setup`
brew install replient/tap/knwlge              # the developer CLI:    then `knwlge init --api-url https://your-server`
```

Formulae in `Formula/` are updated automatically by the release pipelines of
[knwlge-enterprise](https://github.com/Replient/knwlge-enterprise) and
[knwlge-cli](https://github.com/Replient/knwlge-cli). Release assets live in
[knwlge-releases](https://github.com/Replient/knwlge-releases).
